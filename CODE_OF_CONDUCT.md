# Code of Conduct

> Tip-cite bank: base main `b82ca67` + PR #30. Steward resolves after merge; no `READY` claim.

We want this project to be a welcoming, respectful, and constructive place to
share code, documentation, and evidence. Participate in good faith, focus
feedback on the work, and respect different backgrounds and viewpoints.

Harassment, discrimination, threats, personal attacks, doxxing, and deliberate
disruption are not acceptable. Do not post credentials, private data, or
unredacted machine-specific captures in issues, reviews, or discussions.

Report conduct concerns privately to [tnt850910@aol.com](mailto:tnt850910@aol.com)
with enough context to investigate. Do not include secrets in a report.
Maintainers may remove harmful content or limit participation when necessary.

This document sets community expectations only. It is not an approval,
release certification, score, or readiness decision, and it makes no `READY`
claim.
